# ⚖️ Legal Awareness Chatbot

## 📌 Overview
The Legal Awareness Chatbot is a Flask-based AI web application that provides simple and understandable answers to legal-related questions using Google Gemini AI. It helps users get quick legal awareness information in an easy chat format.

---

## 🚀 Live Demo
https://legal-awareness-bot.onrender.com

---

## 🛠️ Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Google Gemini AI API
- Gunicorn (WSGI Server)
- Render Deployment (:contentReference[oaicite:0]{index=0})

---

## ⚙️ Features
- AI-powered legal question answering chatbot  
- Real-time responses using Gemini AI  
- Simple and interactive chat UI  
- Responsive web design  
- Fully deployed and accessible online  

---


---

## 🧠 How It Works
- User enters a legal question in the chat interface  
- Flask backend receives the request  
- Google Gemini API processes the input  
- AI-generated response is returned  
- Response is displayed in the frontend chat UI
